# web-access 适配

仅在用户选择此方式时读取当前环境安装的 `web-access/SKILL.md`，按其版本执行连接检查和 API 调用。这里不复制可能过期的端口、命令参数或路径，也不将其“所有联网默认使用我”的路由扩展到用户选择的其他模式。

确认共享连接属于用户指定的浏览器和登录会话，再创建本任务页面。保留初始页面标识，记录本任务新建页面；已健康的共享代理不重复启动。权限拒绝、连接失效和用户没登录是不同问题，按实际错误诊断。

优先用当前工具提供的 DOM 读取确认笔记身份、正文与图集；需要交互时按实际页面操作。图片必须通过工具支持的截图或图像呈现逐张核读；浏览器在后台、视口为零或懒加载停滞时先检查可见状态，不能把空白截图当读完。

首次采集验证正文、至少一张图及评论展开能工作。失败时按能力缺口处理；只用搜索摘要不可交付完整调研。收尾关闭已登记且确属本任务的页面，保留共享服务和用户原有页。
