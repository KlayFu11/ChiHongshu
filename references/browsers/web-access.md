# web-access 适配

仅在用户选择此方式时读取当前环境安装的 `web-access/SKILL.md`，按其版本执行连接检查和 API 调用。这里不复制可能过期的端口、命令参数或路径，也不将其“所有联网默认使用我”的路由扩展到用户选择的其他模式。

`browser.mode: web-access`。开始前确定下列信息，能从现有配置只读获取的先查：

| 信息 | 前提与填写 |
|---|---|
| 已安装 Skill 与版本 | 确认真实安装路径；按该版本的依赖检查，缺失时告知，不自行安装替代工具。 |
| 目标浏览器 | 用户指定的浏览器用户数据目录/现有 profile，而不是只填“Chrome”。当前 `--browser` 参数若表示数据目录，应按安装版说明填写，不假定永远接受浏览器名称。 |
| 共享连接 | 按当前脚本检查连接是否健康且属于目标浏览器；连接成功与服务仅在运行不同。端口和 API base 来自检查结果，不猜默认端口。 |
| 小红书状态 | 在该连接的任务页观察实际登录；未登录先告知目标环境并等待用户登录，遵守 [通用登录协议](../browser-selection.md)。 |
| 任务页面 | 初始标签标识、本次创建的标签及截图输出目录。 |

确认共享连接属于用户指定的浏览器和登录会话，再创建本任务页面。保留初始页面标识，记录本任务新建页面；已健康的共享代理不重复启动。权限拒绝、连接失效和用户没登录是不同问题，按实际错误诊断。

优先用当前工具提供的 DOM 读取确认笔记身份、正文与图集；需要交互时按实际页面操作。图片必须通过工具支持的截图或图像呈现逐张核读；浏览器在后台、视口为零或懒加载停滞时先检查可见状态，不能把空白截图当读完。

登录复核成功后，首次采集验证正文、至少一张图及评论展开能工作。失败时按能力缺口处理；只用搜索摘要不可交付完整调研。收尾关闭已登记且确属本任务的页面，保留共享服务和用户原有页。
