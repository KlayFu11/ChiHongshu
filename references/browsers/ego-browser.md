# ego-browser 适配

仅在用户选择此方式时读取环境中安装的 ego-browser Skill，按照它要求获取与当前版本一致的 CLI 使用指南。不要把历史版本的空间/页面 ID、profile 名称、命令参数写死在本任务中。

`browser.mode: ego-browser`。需确定：

| 信息 | 前提与填写 |
|---|---|
| CLI 与指南 | 已有安装及可执行命令；按已安装 Skill 要求运行 `ego-browser skill` 读取匹配版本的完整指南，不使用旧会话命令猜参数。 |
| 空间/profile | 用户指定的现有环境、空间和 profile 标识；如果需要独立空间/profile，先解释实际登录影响并让用户决定。不能把“新任务页”误当作已登录的新 profile。 |
| 任务与页面 | 当前任务身份和实际返回的页面 ID；空间撤销或消失时不擅自重建。 |
| 登录和证据 | 该空间的小红书已登录且可查看图片/评论、保存必要图像。未登录先告知在哪个空间登录，等待并复核后再检索。 |

环境选择与记录遵守 [通用协议](../browser-selection.md)。本次仅补充适配说明，不安装/升级 ego 或更改既有空间。

按当前指南确认用户选择的空间、profile、站点登录状态，以及任务页面的创建和结束机制。空间突然消失或授权被撤销时尊重当前状态，不自动复制账号资料或重建用户已关闭的环境。

使用指南所支持的导航、DOM、交互、截图和图像查看方法，逐图核读并检查评论展开。文本快照不等于图片已看；图片保存需符合工具能力和宿主约束。真实浏览验证应覆盖原帖正文、图片及评论，不能用其他网站成功来证明小红书可用。

按当前指南结束本任务空间/页面，保留用户要求保留的内容。只清理明确归属于本任务的资源，不重复执行结束操作或任意关闭其他空间。
