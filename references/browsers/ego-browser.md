# ego-browser 适配

仅在用户选择此方式时读取环境中安装的 ego-browser Skill，按照它要求获取与当前版本一致的 CLI 使用指南。不要把历史版本的空间/页面 ID、profile 名称、命令参数写死在本任务中。

按当前指南确认用户选择的空间、profile、站点登录状态，以及任务页面的创建和结束机制。空间突然消失或授权被撤销时尊重当前状态，不自动复制账号资料或重建用户已关闭的环境。

使用指南所支持的导航、DOM、交互、截图和图像查看方法，逐图核读并检查评论展开。文本快照不等于图片已看；图片保存需符合工具能力和宿主约束。真实浏览验证应覆盖原帖正文、图片及评论，不能用其他网站成功来证明小红书可用。

按当前指南结束本任务空间/页面，保留用户要求保留的内容。只清理明确归属于本任务的资源，不重复执行结束操作或任意关闭其他空间。
