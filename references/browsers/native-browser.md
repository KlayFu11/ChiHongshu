# Agent 原生网页浏览能力适配

指宿主直接提供的网页浏览工具，不是某个名为 browser-use 的第三方产品；不要求额外 Skill 或 MCP。使用当前实际可调用的工具名称和参数，不假定不同宿主具有相同 API。

先检查能力：进入原帖而非仅搜索摘要；读取动态正文；实际查看图集像素；按序加载评论及展开回复；保存必要证据。检查所连接浏览器是否具有用户所选登录状态，不能默认继承日常浏览器账号。

若只能搜索或抓取静态文本，只能完成来源发现，不能标记图片、评论已读，也不能将外部摘要当原帖正文。说明缺失能力，列出可用替代供用户选择，不自行换到 MCP/其他浏览器。

无文件保存能力但能实际看图时，先说明证据图片交付受限，不伪造本地图片文件；按缺失范围保持阶段稿或请求合适工具。保存页面与清理操作只使用宿主已有接口，不发明“通用浏览器 API”。

验证状态：尚未在各宿主的原生浏览工具上进行实时小红书验证。
